# ผลตรวจรุ่นตรวจจับหลายชิ้น

วันที่ 21 พฤศจิกายน 2026 (Asia/Bangkok)

## ผลโมเดลที่วัดจริง

- SSDLite15 กลุ่ม ฝึก 40 epochs จากภาพใช้ได้ 3,652 ภาพ / วัตถุ 6,941 ชิ้น / source groups 2,654 กลุ่ม รวม augmentation ที่ผู้เผยแพร่จัดไว้
- แบ่ง train/validation/test 2,541/563/548 ภาพ กัน source filename และ SHA256 ข้าม split แต่ยังไม่ใช่ physical-item holdout
- ประเมิน exact ONNX ทุกภาพ test 548 ภาพ / วัตถุจริง 960 ชิ้น ใช้ top150 candidates, NMS .45, แสดงสูงสุด10 เช่นเดียวกับเว็บ
- Precision 60.43%, Recall 28.96%, mAP50–95 21.16%, จำนวนตรงทั้งภาพ 57.12%, count MAE 1.0584 ชิ้น
- ผลแบตเตอรี่ recall50% จาก24วัตถุ; ภาชนะมีแรงดัน/แก้วแตก recall0 จากกลุ่มละ2วัตถุ จึงยังใช้รับรองความปลอดภัยไม่ได้
- คะแนน0–100ปรับเทียบด้วย isotonic validation; test ECE .03982 / Brier .14266 ค่าเฉลี่ยต่อรอบคิดเฉพาะรายการที่ตรวจพบ ไม่ใช่ accuracy ของภาพนั้น
- check_model ผ่าน hash, ONNX structure, input/output, labels, calibration และ report ของทั้งโมเดลเดิมและตัวตรวจจับ
