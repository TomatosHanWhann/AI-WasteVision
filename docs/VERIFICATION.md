## ข้อจำกัดของการตรวจ

การควบคุม Chrome ขัดข้องระหว่างเปลี่ยนไปหน้าจำแนก เครื่องมือแจ้ง debugger unattached และหยุดตอบสนอง จึงยังไม่มีภาพหน้าจอ desktop/mobile รุ่นใหม่นี้ และไม่อ้างว่าการตรวจหน้าจอครบทุกขนาดผ่านแล้ว ภาพใน .impeccable/review เดิมเป็นหลักฐานรุ่นก่อน ไม่ใช้รับรองรุ่นนี้ การตรวจ finishing แบบ inline ยังต้อง recapture ก่อนรับรองคุณภาพภาพรวม

การวิเคราะห์ด้วย ONNX ผ่าน Python ไม่ทดแทนการทดสอบ upload/camera ใน browser รุ่นนี้ กล้องจริง iPhone/Android, Safari, p95 latency, physical-item holdout และผู้ใช้ประมาณ 10 คนยังต้องทดสอบเพิ่มเติม ไม่มีการเปลี่ยนสิทธิ์ browser หรือเปิดกล้องส่วนตัวเพื่อหลีกเลี่ยงข้อจำกัดเครื่องมือ

การตรวจและปรับเอกสารออกแบบทำในงานเดียวตามคำขอไม่แบ่งงานให้ผู้อื่น ไม่มีการอ้าง independent reviewer หรือผลทดสอบภาคสนาม
