# ทดสอบตามแผนและบันทึกหลักฐาน

## สิ่งที่ตรวจอัตโนมัติได้

`npm test`: กฎปฏิเสธภาพ ความปลอดภัยของคำแนะนำเมื่อผู้ใช้ระบุอันตราย นิยาม metric ที่นับ rejection และ CSV ที่เปิดใน spreadsheet ได้

`npm run build`: รวมโค้ด ฟอนต์ และ WASM ให้ deploy เป็น static web ได้

`python ml/check_model.py`: ตรวจ ONNX, hash, labels และ metadata/report ว่าตรงรุ่น ไม่ต้องดาวน์โหลด dataset

`python ml/train.py`: ฝึก เลือก hyperparameter จาก validation ทดสอบด้วย ONNX ที่ export จริง และสร้างรายงาน/manifest/predictions ห้ามสรุปว่า image-level split เป็น physical holdout

## ตรวจเว็บบนอุปกรณ์จริง

ทดสอบ Chrome บน Android/desktop และ Safari บน iPhone ที่เปิดผ่าน HTTPS ทำทีละ flow:

1. โหลดโมเดลครั้งแรกและรอข้อความพร้อม ปิด/เปิดเน็ตเพื่อตรวจข้อความผิดพลาดและลองโหลดใหม่
2. อนุญาตกล้อง ถ่ายแนวตั้ง/แนวนอน ตรวจวัตถุอยู่กลางภาพ ไปหน้าอื่นแล้วตรวจไฟกล้องดับ
3. ปฏิเสธสิทธิ์กล้องแล้วใช้อัปโหลดสำรอง ตรวจ JPG/PNG/WebP และไฟล์ผิดชนิด/เสีย/ใหญ่
4. วิเคราะห์ครบ 5 ประเภท รวมภาพนอกขอบเขตและหลายชิ้น ตรวจผลคะแนนและ rejection
5. เปลี่ยนสภาพสะอาด/เปื้อน/อันตราย ตรวจคำแนะนำ ไม่ถือว่า AI พิสูจน์รีไซเคิลได้
6. เลือกคำตอบจริงที่ต่างจาก AI บันทึกหนึ่งครั้ง ตรวจหน้า metrics รีโหลดแล้วข้อมูลยังอยู่
7. ส่งออก CSV เปิดใน Excel/Sheets ตรวจภาษาไทย เลขความมั่นใจ model_version และ latency
8. QR เปิดจากมือถืออีกเครือข่ายได้ กดคัดลอกลิงก์ได้
9. ทดสอบคีย์บอร์ด focus/labels, 390px และซูม 200% ปิด motion ตามการตั้งค่าอุปกรณ์

## ทดสอบวัตถุใหม่ตามแผน

เตรียมวัตถุที่ไม่เคยใช้ฝึก 40 ชิ้น (คลาสละ 8) + นอกขอบเขต 10 ชิ้น กำหนดรหัสวัตถุ anonymous ถ่ายในห้อง/กลางแจ้ง หลายแสงและฉากหลัง ภาพของชิ้นเดียวกันต้องไม่กลับไปฝึกแล้วอ้างเป็น test อีก

บันทึกคำตอบจริงโดยตรวจวัสดุ ไม่อิง AI เก็บ source=camera/upload แยกจาก dataset-example จด item_id, light, browser และ session_code เพิ่มในสำเนา CSV ใช้แบบใน `field-test-template.csv` ไม่มีชื่อ/รหัสนักศึกษา

รายงาน confusion matrix, precision/recall/F1 ต่อคลาส, macro F1, rejection ของ known/unknown, coverage, median/p95 latency หลังโมเดลพร้อม พร้อมตัวอย่างที่ผิด ห้ามลบภาพที่ AI ไม่แน่ใจเพื่อทำให้ผลดีขึ้น เป้าหมายในแผน Macro F1 ≥0.80 และ inference ≤2 วินาที ยังต้องพิสูจน์จริง

## ผู้ใช้ประมาณ 10 คน

ทดลองแยกเองและใช้ AI กับชุดวัตถุเทียบเคียงกัน สลับลำดับระหว่างคน เก็บ correctness/time/confidence/satisfaction โดยใช้รหัส session ไม่เก็บชื่อ ตัวเลือก “ลองตอบเองก่อนดู AI” ช่วยบันทึก unaided_label แต่ไม่ใช่งานวิจัยก่อน/หลังที่ควบคุมตัวแปรครบถ้วน
