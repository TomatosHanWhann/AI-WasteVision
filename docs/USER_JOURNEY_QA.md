## รายละเอียดที่แก้จากการตรวจ

- เพิ่มaria-labelให้ปุ่มแชร์ซึ่งซ่อนข้อความบนมือถือ
- แสดงข้อความโหลดโมเดลบนปุ่มวิเคราะห์และaria-busyให้สถานะชัด
- serialiseคำขอเปิด/refresh/closeบัตร ไม่ให้ผลเก่าทับสถานะใหม่ ปลดล็อกเมื่อผิดพลาดและล้างสถานะเมื่อsessionหมดอายุ
- เพิ่มฟอนต์self-hosted, safe-area bottom navigation, field16px และยุบfeedbackที่เป็นทางเลือก
- ชุดทดสอบอัตโนมัติหลังแก้22กรณีผ่าน ทั้งโมเดลผ่านcontract check ส่วนbrowserหลังแก้ท้ายรอบถูกจำกัดตามเหตุข้างต้น

## ก่อนกล่าวว่าผ่านครบวงจร

ต้องตรวจจากอุปกรณ์จริงหรือbrowserที่มีสิทธิ์ถูกต้องอีกครั้ง: อัปโหลดภาพของตน→วิเคราะห์→ยืนยันรายชิ้น→แต้มเพิ่ม→เปิดบัตรเดิมอีกครั้ง→ส่งfeedbackโดยไม่แนบภาพ/แนบภาพแยกconsent→ลบข้อมูลและภาพ→ปิดบัตร ตรวจปฏิเสธสิทธิ์กล้อง ไฟล์เสีย/ผิดชนิด/ใหญ่ และเน็ตหลุดด้วย

เก็บผลAndroid/iPhone/Safari,320px/430px/tablet, zoom200%, screen reader, การเพิ่มหน้าจอหลักและp95เพิ่มเติม ไม่ใช้การจำลองviewportแทนผลอุปกรณ์จริง
