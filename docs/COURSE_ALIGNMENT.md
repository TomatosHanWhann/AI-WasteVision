## สถานะที่ต้องแยกให้ชัด

- **ทำงานแล้ว:** ตรวจวัสดุ/วัตถุ, นับสิ่งที่ตรวจพบ, คำแนะนำตามกฎ, บัตร, ค้นบันทึกคำแนะนำพร้อมลิงก์ต้นทาง, ชุดทดลอง baseline และชุดประเมิน retrieval
- **เตรียมให้ทดลองได้:** เครื่องมือเรียก Ollama และ OpenRouter ด้วยโจทย์ชุดเดียวกัน บันทึกคำตอบ เวลา token usage และแบบตรวจโดยคน
- **ยังไม่มีผลยืนยัน:** LLM local/API จริง, embeddings/Transformer, RAG แบบ generative บนเว็บ, ผลจากขยะใช้แล้วไทยที่แยกวัตถุจริง, โมเดลตรวจจับรุ่นใหม่ที่ดีขึ้น

การมี Worker API สำหรับบัตรไม่ใช่หลักฐานการใช้ LLM ผ่าน API และการค้น TF-IDF ไม่ใช่ LLM/RAG แบบสร้างคำตอบ การเปลี่ยน UI และเพิ่มแหล่งข้อมูลข้อความไม่เพิ่มความแม่นยำของโมเดลภาพโดยอัตโนมัติ

## การเตรียมข้อมูลไทยรอบต่อไป

1. ใช้วัตถุจริงที่ทีมมีสิทธิ์ถ่าย ไม่อาศัยภาพสินค้าใหม่แทนของใช้แล้วทั้งหมด บันทึกวัสดุ สภาพ แบรนด์ (ถ้ามี) ฉากหลัง แสง และจำนวนจริง โดยไม่ถ่ายใบหน้าหรือข้อมูลส่วนบุคคล
2. ให้รหัส `physical_item_id` เดียวแก่ภาพขยะชิ้นเดิมทุกมุม และ `session_id` แก่รอบถ่ายเดียวกัน ภาพกลุ่มที่มีวัตถุใดซ้ำกันต้องอยู่ split เดียวกันทั้งหมด (กรณีหลายชิ้นควรทำ connected groups เพิ่ม)
3. กำหนด split ก่อน augmentation เก็บ test ไว้ ไม่ใช้เลือกรุ่นหรือ threshold ควรมีทั้งภาพง่าย/ยากและหมวดอันตรายที่เก็บได้อย่างปลอดภัย ไม่สร้างสถานการณ์เสี่ยงเพื่อถ่ายภาพ
4. ใช้ [ตัวอย่าง manifest](thai-field-manifest.example.csv) เป็นแบบกรอก ไม่ใช่ข้อมูลที่เก็บแล้ว ตั้ง `group_id` เท่ากับ `physical_item_id` สำหรับตัวจำแนกภาพหนึ่งชิ้น
5. รัน `python ml/validate_field_manifest.py ml/data/thai-field/manifest.csv` ตัวตรวจปฏิเสธวัตถุ รอบถ่าย หรือ SHA256 ที่ข้าม split รวมถึงข้อมูลสิทธิ์ไม่ครบ แต่ไม่สามารถยืนยันว่ามนุษย์ระบุรหัสหรือ label ถูก
6. Detection ต้องมีกรอบ/ชนิดรายวัตถุที่ตรวจทานเพิ่มเติม CSV อย่างเดียวไม่พอ เริ่มจากเครื่องมือ feedback/review เดิมและเก็บชุดทดสอบภาคสนามแยกไว้
7. ฝึก candidate ใน branch/checkout ทดลอง อย่าเขียนทับ `public/model/` รุ่นใช้งานโดยไม่ตรวจผล เลือกรุ่นด้วย validation แล้วประเมิน test เพียงครั้งตามแผนที่กำหนด รายงานทั้งภาพที่ดีขึ้นและแย่ลง

ไฟล์ validator ช่วยตรวจข้อมูลที่ทีมบันทึก ไม่ได้ทำให้ข้อมูลเดิมเป็น physical-item holdout และยังไม่มีการอ้างว่ารวบรวมภาพไทยรอบใหม่เสร็จแล้ว
