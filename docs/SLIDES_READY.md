# โครงสไลด์ AI WasteVision สำหรับ CE564

ใช้ข้อความนี้เป็นร่าง ผู้จัดทำต้องเข้าใจและตรวจตัวเลขจากไฟล์ต้นทางก่อนนำเสนอ ไม่กล่าวว่าระบบผ่านทุก CLO หรือรับรองความปลอดภัยแล้ว

## สไลด์ 1 · ปัญหาและวัตถุประสงค์

- ผู้ใช้พบวัสดุหลายชนิดและอาจไม่ทราบวิธีแยกส่งที่เหมาะสม
- AI WasteVision เป็นเว็บทดลองภาษาไทย ช่วยระบุวัสดุ ตรวจจับและนับสิ่งที่พบ พร้อมคำแนะนำและแหล่งข้อมูล
- ใช้มือถือเป็นหลัก เปิดผ่านลิงก์โดยไม่ต้องติดตั้งหรือเปิดบัตรเพื่อวิเคราะห์

## สไลด์ 2 · ลำดับการใช้งาน

เลือก/ถ่ายภาพ → วิเคราะห์บนอุปกรณ์ → ตรวจกรอบและจำนวนที่พบ → อ่านประเภทและระดับความมั่นใจ → ระบุสภาพและตรวจคำแนะนำจุดทิ้ง → ยืนยันแต้มเฉพาะรายการที่เข้าเงื่อนไข

ค้นคำแนะนำเพิ่มเติมได้ในหน้าวิธีใช้ โดยพิมพ์คำถามและเปิดแหล่งอ้างอิง บัตรเป็นกิจกรรมส่งเสริมการใช้งาน ไม่ใช่หลักฐานการรับขยะจริง

## สไลด์ 3 · สถาปัตยกรรม

- Browser: กล้อง/ภาพ, preprocessing, ONNX Runtime, โมเดลภาพ, กฎคัดแยก และ TF-IDF retrieval
- Worker API: session, scan ticket, แต้ม, feedback, สถิติ และ advice endpoint สำหรับการบูรณาการ
- D1: ข้อมูลบัตร/เหตุการณ์/feedback; R2: ภาพที่ผู้ใช้ยินยอมแนบโดยเฉพาะ
- GitHub: source, รายงาน, tests และ CI; Sites: เว็บที่เผยแพร่ การ push GitHub ไม่ deploy Sites อัตโนมัติ

## สไลด์ 4 · โมเดลภาพและผลที่มีอยู่

| งาน | โมเดล | ผลหลัก |
| --- | --- | --- |
| จำแนกวัสดุหลัก | MobileNetV2 features + classifier v2 | known test532ภาพ Accuracy82.14%, Macro F1 0.8423 ก่อนปฏิเสธผล |
| ตรวจจับหลายชิ้น | SSDLite MobileNetV3 v3 | test548ภาพ/960วัตถุ Precision60.43%, Recall28.96%, mAP50–95 21.16%, count MAE1.0584ชิ้น |

ตัวเลขเป็นงานคนละประเภท ห้ามนำ accuracy ของ classifier ไปอ้างว่า detector ตรวจถูก82.14% ผลเดิมเป็น public/product data ยังไม่ใช่ชุดทดสอบขยะใช้แล้วไทยที่แยกวัตถุจริง

## สไลด์ 5 · การทดลองที่เพิ่มเพื่อรายวิชา

HOG + colour histogram + Linear SVM เทียบ MobileNetV2 เดิมบน test532ภาพชุดเดียวกัน:

| ระบบ | Accuracy | Macro F1 |
| --- | ---: | ---: |
| HOG+สี+SVM | 60.15% | 0.6033 |
| MobileNetV2 รุ่นเดิม | 82.14% | 0.8423 |

เลือก C ด้วย validation เท่านั้น ผลสนับสนุนการเลือกใช้ pretrained CNN representation ในระบบนี้ แต่ training setup ไม่เหมือนกันทุกส่วน จึงไม่ใช่ architecture-only ablation ไม่ได้เพิ่ม accuracy ของโมเดล production

หลักฐาน `ml/results/course-baseline.json`, `course-baseline-predictions.csv` และ [EXPERIMENTS.md](EXPERIMENTS.md)

## สไลด์ 6 · ส่วนภาษาและการค้นคืน

- บันทึกสรุปภาษาไทย8หัวข้อจากแหล่งข้อมูล กรุงเทพมหานคร/กรมควบคุมมลพิษ
- Character n-gram TF-IDF และ cosine similarity ร่วมกับการตรวจหัวข้อ/ปฏิเสธนอกขอบเขต
- แสดงข้อความอ้างอิงและลิงก์ต้นทาง ประมวลผลคำถามบนอุปกรณ์
- ชุด regression ของผู้พัฒนา24คำถาม: ตรงอันดับแรก18/18ข้อที่มีข้อมูล และปฏิเสธนอกขอบเขต6/6ข้อ
- ชุดคำถามนี้ใช้ระหว่างพัฒนา ไม่ใช่ independent holdout; ตัวเลขไม่ใช่ accuracy ของ LLM

## สไลด์ 7 · การต่อยอด LLM และ RAG

**สถานะ: เตรียมเครื่องมือทดลอง ยังไม่เปิด LLM บนเว็บ**

คำถาม → ค้นบันทึกอ้างอิง → ประกอบ prompt → local Ollama หรือ OpenRouter API → คนตรวจ grounding/แหล่งอ้างอิง/ภาษาไทย

มี CLI บันทึกคำตอบ เวลาและ token usage ด้วยคำถามชุดเดียวกัน แต่ยังไม่มีผลจริงของ local/API หรือ quantization ไม่ใส่ตัวเลขสมมติลงสไลด์ หัวข้ออันตรายใช้คำแนะนำที่คัดเลือกและกฎเดิม

## สไลด์ 8 · ความเกี่ยวข้องกับเนื้อหาวิชา

- CLO1: เลือก train/workflow/API ให้เหมาะกับหน้าที่
- CLO2: เตรียมข้อมูล split ฝึก baseline ปรับ C และประเมินด้วย metrics
- CLO3: transfer learning, CNN, detection และ NLP แบบ TF-IDF (ยังไม่ใช่ deep NLP)
- CLO4: local inference, API และโครงทดลองต่อยอด generative RAG (LLM ยังไม่ทดลองจริง)
- CLO5: เว็บและ Git ที่ทำงานได้ กระบวนการตรวจสอบ สิทธิ์ข้อมูล ความยินยอม และเปิดเผยการใช้ AI

อ้างอิง syllabus CE564 หน้า4–5,7–9 และ [COURSE_ALIGNMENT.md](COURSE_ALIGNMENT.md) ยังไม่ถือว่าครบทุกหัวข้อในรายวิชา

## สไลด์ 9 · ข้อจำกัดและแนวทางพัฒนา

- ความมั่นใจ0–100เป็นค่าประมาณ ไม่ใช่หลักฐานว่ารอบนั้นถูกกี่เปอร์เซ็นต์ วัตถุที่ตกหล่นไม่อยู่ในค่าเฉลี่ยคะแนน
- Recall detectorยังต่ำ ต้องเพิ่มข้อมูลใช้แล้วจริงและลด false negatives โดยเฉพาะกลุ่มอันตราย
- ภาพตัวอย่างแบรนด์ไทยไม่ใช่ระบบรู้จำแบรนด์ และไม่ทดแทน field holdout
- เพิ่มชุดภาพแยก physical item/session, กรอบวัตถุที่ตรวจทาน และคำถามอิสระ
- ทดสอบ UI/กล้อง/มือถือจริงเพิ่มเติมและทดลอง LLM ก่อนอ้างประสิทธิภาพ
- ใช้ AI ช่วยพัฒนา ต้องเปิดเผยบทบาทและอธิบายผลงานได้ ดู [AI_USAGE_DISCLOSURE.md](AI_USAGE_DISCLOSURE.md)

## สาธิตที่แนะนำ

1. เปิด [เว็บหลัก](https://ai-wastevision-th.tenderheron1024.chatgpt.site) แสดงภาพรวมและข้อจำกัด
2. เลือกภาพตัวอย่างหลายชิ้น แสดงจำนวนที่พบ/กรอบ/คะแนน และข้อควรระวัง ภาพนี้เป็นตัวอย่างจากชุดเดิม ไม่ใช่ independent test ใหม่
3. เปิดวิธีใช้ ถาม “กล่องนมต้องล้างก่อนทิ้งหรือไม่” และเปิดแหล่งอ้างอิง
4. ถามนอกขอบเขต เช่น “เมืองหลวงของฝรั่งเศสคืออะไร” ให้เห็นการปฏิเสธ
5. เปิดรายงาน baseline และอธิบายความต่างของ accuracy/recall/retrieval hit พร้อมข้อจำกัด

ก่อนสาธิตจริงให้ทีมทดสอบอุปกรณ์และเครือข่ายที่จะใช้ กล้อง/อัปโหลด/feedbackครบวงจรยังต้องตรวจเพิ่มเติม ไม่กล่าวว่าทุกฟังก์ชันผ่านการทดสอบแล้ว
